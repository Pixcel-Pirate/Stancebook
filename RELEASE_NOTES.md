## What's new

- **Friendlier to antivirus:** the installer no longer force-closes apps. If Stancebook is open, it asks you to close it. It also has a welcome page, proper version details and no auto-opened web links.
- **Safer uninstall:** the uninstaller only removes Stancebook's own files.
- **Safer builds:** the release checks the desktop engine against a known fingerprint and keeps its GitHub key away from build tools. Each release lists the installer's SHA-256 so you can verify the download.
- Offline use no longer logs errors.
