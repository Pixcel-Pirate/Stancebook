## What's new

- **Oct 15 patch:** Forever notes for all nine classes, including the Arcane Blast redesign, Paladin Salvation, the Hunter Auto Shot delay and the longer Shadow Priest cooldowns.
- **Talents refreshed** for Mage, Priest, Shaman and Warlock from wowforevertalents (Oct 16 data). Saved builds that used removed talents are adjusted automatically.
- **Safer:** saved data is checked before it's used, so a damaged save can't break the book. The action bar only accepts real macros, and the update check only trusts real release tags.
- **Leaner release build:** the old unused desktop toolchain was removed, the build no longer runs package install scripts, and the build tools are pinned to exact versions.
